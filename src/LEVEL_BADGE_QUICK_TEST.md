# ⚡ Level Badge - Quick Test Guide

## 🎯 Быстрое визуальное тестирование

### 1. Откройте приложение

Запустите приложение и перейдите на главный экран (Home Screen).

---

### 2. Найдите Level Badge

**Расположение:** Верхняя панель, внутри прогресс-бара

```
┌────────────────────────────────────────┐
│ [Menu] [🎖️12 Daily Goal] [💰 1580]   │  ← ЗДЕСЬ!
│                                        │
│ ══════════════════════════ 85%         │
└────────────────────────────────────────┘
```

---

### 3. Проверьте внешний вид

#### ✅ Визуальные элементы:

- [ ] **Круглая форма** (rounded-full)
- [ ] **Белая рамка** 2px с небольшой прозрачностью
- [ ] **Градиент** (цвет зависит от уровня):
  - Уровень 1-4: Светло-розовый
  - Уровень 5-9: Розовый
  - Уровень 10-14: Голубой (с искоркой ✨)
  - Уровень 15-19: Фиолетовый (с искоркой ✨)
  - Уровень 20+: Золотой (с искоркой ✨)
- [ ] **Номер уровня** белым жирным шрифтом
- [ ] **Мягкая тень** под бейджем

---

### 4. Проверьте hover эффект

**Наведите курсор на бейдж:**

- [ ] Бейдж **увеличивается** (scale 1.1x)
- [ ] Появляется **shimmer эффект** (блестящая полоса)
- [ ] Курсор меняется на **pointer**

---

### 5. Проверьте искорку (уровень 10+)

Если ваш уровень **10 или выше**:

- [ ] В правом верхнем углу есть **анимированная искорка** ✨
- [ ] Искорка **пульсирует** (animate-pulse)

---

### 6. Проверьте разные сценарии

#### Сценарий A: Стадия эволюции (Baby/Teenager)

```
[🎖️8 Baby Papi → teenager] [35,000 steps]
```

- [ ] Level Badge показывается **слева от названия стадии**
- [ ] Номер уровня корректный

#### Сценарий B: Взрослая стадия (Adult)

```
[🎖️12 Daily Goal] [8,500 / 10,000]
```

- [ ] Level Badge показывается **слева от "Daily Goal"**
- [ ] Номер уровня корректный

---

## 🧪 Тестирование разных уровней

### Изменить уровень для тестирования

Откройте **DevTools (F12)** → **Console** и выполните:

```javascript
// Установить уровень 1 (Light Pink)
localStorage.setItem('testTotalSteps', '1000');
location.reload();

// Установить уровень 5 (Pink)
localStorage.setItem('testTotalSteps', '31000');
location.reload();

// Установить уровень 10 (Blue с искоркой)
localStorage.setItem('testTotalSteps', '1023000');
location.reload();

// Установить уровень 15 (Purple с искоркой)
localStorage.setItem('testTotalSteps', '32767000');
location.reload();

// Установить уровень 20 (Gold с искоркой)
localStorage.setItem('testTotalSteps', '1048575000');
location.reload();
```

**После каждого изменения:**
- [ ] Проверьте правильность **номера уровня**
- [ ] Проверьте правильность **цвета градиента**
- [ ] Проверьте наличие **искорки** (для уровня 10+)

## 🐛 Если что-то не работает

### Проблема: Level Badge не отображается

**Решение:**
```javascript
// Проверьте импорт в EvolutionProgress.tsx
import { LevelBadge } from './LevelBadge';
import { calculateLevel } from '../utils/levelSystem';

// Проверьте, что компонент рендерится
console.log('Current level:', calculateLevel(totalSteps));
```

### Проблема: Неправильный цвет градиента

**Проверка:**
```javascript
// В DevTools
const level = 12;
// Для уровня 12 должен быть голубой градиент
```

### Проблема: Искорка не появляется на уровне 10+

**Проверка:**
```javascript
// В LevelBadge.tsx, строка 66-70
{level >= 10 && (
  <div className="absolute -top-0.5 -right-0.5 text-[8px] animate-pulse">
    ✨
  </div>
)}
```
