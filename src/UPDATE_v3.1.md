## ✨ Новые Функции

### 1. 💬 Dynamic Papi Phrases System

**Описание:**  
Папи теперь говорит с пользователями с помощью 30+ уникальных фраз, которые автоматически выбираются на основе его эмоционального состояния.

**Категории Фраз:**

| Категория | Условие | Количество | Примеры |
|-----------|---------|------------|---------|
| 🟢 **Happy** | Средний уровень > 70% | 14 фраз | "I'm so happy to see you! ☀️" |
| 🟡 **Neutral** | Средний уровень 40-70% | 8 фраз | "Hey, I'm getting a little hungry 🍽️" |
| 🔴 **Sad** | Средний уровень < 40% | 8 фраз | "I'm feeling a bit lonely… 🥺" |

**Технические Детали:**
- Средний уровень = (Hunger + Fun + Energy) / 3
- Фраза обновляется при открытии речевого пузыря
- Фраза меняется при переходе между категориями настроения
- Гарантирует, что новая фраза отличается от предыдущей

**Новые Файлы:**
- `/utils/papiPhrases.ts` - Система фраз и логика выбора
- `/PAPI_PHRASES_SYSTEM.md` - Полная документация
- `/QUICK_PHRASES_GUIDE.md` - Быстрое руководство

**Обновлённые Файлы:**
- `/components/PapiSpeechBubble.tsx` - Добавлена поддержка динамических фраз
- `/components/screens/KawaiiHomeScreen.tsx` - Передача состояния в речевой пузырь

### 2. 🦋 Butterfly Event (замена мухи)

**Изменения:**
- **Старый символ:** 🪰 (муха)
- **Новый символ:** 🦋 (бабочка)

**Улучшения анимации:**
```typescript
// Было (муха):
animate={{ x: [0, 5, -5, 0], y: [0, -3, 3, 0] }}
transition={{ duration: 0.5, repeat: Infinity, ease: 'easeInOut' }}

// Стало (бабочка):
animate={{ x: [0, 8, -8, 0], y: [0, -5, 5, 0], rotate: [0, 5, -5, 0] }}
transition={{ duration: 1.2, repeat: Infinity, ease: 'easeInOut' }}
```

**Результат:**
- Более плавное и грациозное движение
- Добавлено вращение для реалистичности
- Увеличена амплитуда движения
- Замедлена анимация для большей элегантности

**Обновлённые Файлы:**
- `/components/events/FlyEvent.tsx` - Новая анимация бабочки
- `/RANDOM_EVENTS_SYSTEM.md` - Обновлённое описание события
- `/TESTING_RANDOM_EVENTS.md` - Обновлённые тестовые кейсы

## 🔧 Технические Детали

### Новые Функции API

#### `calculateAverageState(hunger, fun, energy): number`
Вычисляет средний уровень состояния питомца.

#### `getMoodCategory(averageState): 'happy' | 'neutral' | 'sad'`
Определяет категорию настроения.

#### `getRandomPhrase(hunger, fun, energy): PapiPhrase`
Возвращает случайную фразу из соответствующей категории.

#### `getNewRandomPhrase(hunger, fun, energy, previousTitle?): PapiPhrase`
Гарантирует уникальность новой фразы.

## 🧪 Тестирование

### Как Протестировать Dynamic Phrases

**Test Case 1: Happy Phrases**
1. Установить все индикаторы на 80%+
2. Открыть речевой пузырь
3. **Ожидается:** Весёлая фраза (например, "I'm so happy to see you! ☀️")

**Test Case 2: Neutral Phrases**
1. Установить все индикаторы на 50-60%
2. Открыть речевой пузырь
3. **Ожидается:** Нейтральная фраза (например, "Hey, I'm getting a little hungry 🍽️")

**Test Case 3: Sad Phrases**
1. Установить все индикаторы на 10-30%
2. Открыть речевой пузырь
3. **Ожидается:** Грустная фраза (например, "I'm feeling a bit lonely… 🥺")

**Test Case 4: Phrase Change**
1. Открыть пузырь → фраза A
2. Закрыть пузырь
3. Открыть снова → фраза B (другая!)
4. **Ожидается:** Фразы не повторяются

### Как Протестировать Butterfly Event

**Test Case 1: Butterfly Spawn**
1. Сбросить cooldown событий
2. Подождать появления бабочки
3. **Ожидается:** Символ 🦋 с плавной анимацией

**Test Case 2: Butterfly Animation**
1. Наблюдать за движением бабочки
2. **Ожидается:** Волнообразное движение с лёгким вращением

**Test Case 3: Butterfly Catch**
1. Тапнуть по бабочке
2. **Ожидается:** Toast "🦋 Butterfly caught!" и +50 монет

## 📝 Заметки для Разработчиков

### Как Добавить Новую Категорию Настроения

1. Обновить `getMoodCategory()` в `/utils/papiPhrases.ts`
2. Добавить новый массив фраз (например, `EXCITED_PHRASES`)
3. Обновить логику в `getRandomPhrase()` и `getNewRandomPhrase()`
4. Обновить документацию

### Как Изменить Пороги Настроения

Текущие пороги:
```typescript
if (averageState > 70) return 'happy';
if (averageState >= 40) return 'neutral';
return 'sad';
```

Измените значения 70 и 40 в функции `getMoodCategory()`.
