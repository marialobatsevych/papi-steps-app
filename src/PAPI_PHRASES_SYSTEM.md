# 💬 Papi Phrases System

## Обзор

Система случайных фраз для создания ощущения живого общения с питомцем Papi. Фразы меняются динамически в зависимости от состояния питомца (голод, веселье, энергия).

---

## 🎭 Категории Настроения

Система автоматически определяет настроение Папи на основе среднего значения всех трёх показателей (hunger, fun, energy).

### 🟢 Счастливое (Happy) — выше 70%

**Характеристика:**
- Папи чувствует себя отлично
- Все индикаторы в зелёной зоне
- Позитивный и игривый тон

**Примеры фраз:**
- "I'm so happy to see you! ☀️"
- "You're my favorite human 💕"
- "Let's have fun together today! 🎉"
- "You're amazing — don't forget that 💛"

---

### 🟡 Нейтральное (Neutral) — 40–70%

**Характеристика:**
- Папи в норме, но мог бы быть и получше
- Некоторые индикаторы начинают снижаться
- Мягко намекает на потребности

**Примеры фраз:**
- "Hey, I'm getting a little hungry 🍽️"
- "Wanna hang out for a bit?"
- "It's been a while since we played! 🐾"
- "A small snack would make me super happy 🍏"

---

### 🔴 Грустное (Sad) — ниже 40%

**Характеристика:**
- Папи нуждается в заботе
- Индикаторы в красной зоне
- Просит о внимании

**Примеры фраз:**
- "I'm feeling a bit lonely… 🥺"
- "Where are you? I miss you 💔"
- "I'm waiting for your care 💛 / Tap an icon to feed or play!"
- "Don't forget about me… 🌧️"

## 🔧 Техническая Реализация

### Файлы

```
/utils/papiPhrases.ts         ← Логика и банк фраз
/components/PapiSpeechBubble.tsx  ← Компонент речевого пузыря
```

### Функции

#### `calculateAverageState(hunger, fun, energy): number`
Вычисляет средний уровень состояния питомца (0-100).

#### `getMoodCategory(averageState): 'happy' | 'neutral' | 'sad'`
Определяет категорию настроения на основе среднего значения.

#### `getRandomPhrase(hunger, fun, energy): PapiPhrase`
Возвращает случайную фразу из соответствующей категории.

#### `getNewRandomPhrase(hunger, fun, energy, previousTitle?): PapiPhrase`
Гарантирует, что новая фраза отличается от предыдущей.

## 🎨 Пользовательский Опыт

### Когда меняется фраза?

1. **При открытии речевого пузыря** — всегда новая случайная фраза
2. **При смене категории настроения** — если состояние питомца значительно изменилось
3. **НЕ меняется** при мелких колебаниях значений внутри одной категории

### Почему это важно?

- **Разнообразие:** Пользователь не видит одну и ту же фразу постоянно
- **Эмоциональная связь:** Создаётся впечатление, что Папи "думает" и "говорит"
- **Контекстность:** Фразы соответствуют реальному состоянию питомца
- **Стабильность:** Фраза не мелькает при каждом небольшом изменении

## 📝 Добавление Новых Фраз

Чтобы добавить новые фразы, отредактируйте `/utils/papiPhrases.ts`:

```typescript
// Добавьте в соответствующий массив
const HAPPY_PHRASES: PapiPhrase[] = [
  { title: "Your new phrase here! 🎉" },
  // ...
];
```

### Формат Фразы

```typescript
interface PapiPhrase {
  title: string;        // Основная фраза (обязательно)
  subtitle?: string;    // Дополнительный текст (опционально)
}
```

**Примеры:**

```typescript
// Только заголовок
{ title: "I'm so happy! 😊" }

// С подзаголовком
{ 
  title: "I'm waiting for your care 💛", 
  subtitle: "Tap an icon to feed or play!" 
}
```

## 🎯 Рекомендации по Фразам

### ✅ Хорошо:
- Короткие и ёмкие (до 50 символов для title)
- Эмодзи в конце или в середине
- Дружелюбный тон
- Эмоциональная окраска соответствует категории

### ❌ Избегать:
- Длинные предложения (более 60 символов)
- Слишком много эмодзи
- Негативные или агрессивные фразы
- Технический жаргон

## 🧪 Тестирование

### Проверить разные категории:

1. **Happy (70%+):** Установить все индикаторы на 80-100%
2. **Neutral (40-70%):** Установить все индикаторы на 50-60%
3. **Sad (0-40%):** Установить все индикаторы на 10-30%

### Как тестировать:

1. Открыть речевой пузырь (он появляется автоматически на главном экране)
2. Изменить состояние питомца (покормить, поиграть)
3. Закрыть и открыть пузырь снова — должна появиться новая фраза
4. Довести состояние до другой категории — фраза должна поменяться
