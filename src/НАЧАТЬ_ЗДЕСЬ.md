## ⚡ Быстрый Старт (3 Шага)

### 1️⃣ Установить Зависимости
```bash
npm install
```

### 2️⃣ Запустить Сервер Разработки
```bash
npm run dev
```
Откройте **http://localhost:5173** в браузере

### 3️⃣ Протестировать Новый Опыт Пользователя
- Увидите экран входа
- Выберите страну
- Познакомитесь с Papi на стадии Birth 🥚
- Получите первый дневной бонус 🎁

## 🎁 Система Бонусов

### Ежедневный Бонус
- **Частота**: Каждые 24 часа
- **Содержимое**: 1 еда + 1 игрушка
- **Еда**: 9 видов (🥕🍚🐟🍪🦴🍌🧁🍗🥩)
- **Игрушки**: 6 видов (🎾🧶🧩🎲🧸🚀)

### Монеты
- **Заработок**: 300 монет за дневную цель
- **Старт**: 0 монет
- **Использование**: Магазин (будущая функция)

## 🌟 Основные Функции

### Система Эволюции
- 🥚 **Рождение**: 0-10,000 шагов
- 👶 **Малыш**: 10,001-20,000 шагов
- 🧒 **Подросток**: 20,001-30,000 шагов
- 🐕 **Взрослый**: 30,001+ шагов

После достижения стадии Взрослый:
- Переключение на **ежедневные цели**
- Цель: 3,000-30,000 шагов в день
- Награда: 300 монет за достижение цели

### Интеграции
- **Google Fit**: Подсчет шагов (Android)
- **Геолокация**: Функция "Друзья рядом"
- **Уведомления**: Напоминания о состоянии Papi
