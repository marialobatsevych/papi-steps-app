# 💬 Quick Guide: Papi Phrases System

## 🎯 Быстрый Старт

Папи теперь говорит с вами! Фразы меняются автоматически в зависимости от его настроения.

---

## 🔍 Как Это Работает?

### Автоматический Выбор Фраз

Система считает среднее значение **Hunger + Fun + Energy** и выбирает фразу:

| Настроение | Средний уровень | Тип фраз | Количество |
|------------|-----------------|----------|------------|
| 🟢 **Happy** | 70%+ | Радостные, игривые | 14 фраз |
| 🟡 **Neutral** | 40-70% | Мягкие напоминания | 8 фраз |
| 🔴 **Sad** | 0-40% | Просьбы о заботе | 8 фраз |

---

## 💡 Примеры Фраз

### 🟢 Когда Папи счастлив (70%+)
```
"I'm so happy to see you! ☀️"
"You're my favorite human 💕"
"Let's have fun together today! 🎉"
```

### 🟡 Когда Папи нормально (40-70%)
```
"Hey, I'm getting a little hungry 🍽️"
"It's been a while since we played! 🐾"
"A small snack would make me super happy 🍏"
```

### 🔴 Когда Папи грустит (ниже 40%)
```
"I'm feeling a bit lonely… 🥺"
"Where are you? I miss you 💔"
"Don't forget about me… 🌧️"
```

---

## 🎨 Где Увидеть Фразы?

Фразы появляются в **речевом пузыре** на главном экране.

**Когда появляется:**
- При входе в приложение
- После выполнения действий
- Периодически (если долго не взаимодействуете)

**Когда меняется:**
- При открытии пузыря
- При смене категории настроения (happy → neutral → sad)
- НЕ мелькает при маленьких изменениях

---

## ✏️ Как Добавить Свои Фразы?

1. Откройте файл `/utils/papiPhrases.ts`
2. Найдите нужный массив:
   - `HAPPY_PHRASES` — для счастливых
   - `NEUTRAL_PHRASES` — для нейтральных
   - `SAD_PHRASES` — для грустных

3. Добавьте новую фразу:

```typescript
const HAPPY_PHRASES: PapiPhrase[] = [
  { title: "Your awesome phrase! 🎉" },
  // ... остальные фразы
];
```

4. С подзаголовком (опционально):

```typescript
{ 
  title: "Main text here 💛", 
  subtitle: "Additional info here" 
}
```

## 🧪 Как Протестировать?

### Проверить Happy фразы (70%+)
1. Покормите Папи до 80%+
2. Поиграйте с ним до 80%+
3. Дайте отдохнуть до 80%+
4. Откройте речевой пузырь → увидите весёлую фразу

### Проверить Sad фразы (ниже 40%)
1. Не кормите Папи (hunger → 20%)
2. Не играйте с ним (fun → 20%)
3. Не давайте спать (energy → 20%)
4. Откройте речевой пузырь → увидите грустную фразу

### Проверить Смену Фраз
1. Откройте пузырь → увидите фразу #1
2. Закройте пузырь
3. Откройте снова → увидите фразу #2 (другую!)

## 📊 Статистика

- **Всего фраз:** 30
- **Языки:** English (планируется Russian)
- **Категорий:** 3 (Happy, Neutral, Sad)

---

## 🎯 Советы

✅ **Хорошие практики:**
- Короткие фразы (до 50 символов)
- Один эмодзи в конце
- Дружелюбный тон
- Соответствие категории

❌ **Избегайте:**
- Длинные предложения
- Много эмодзи подряд
- Негативный тон
- Сложные слова
